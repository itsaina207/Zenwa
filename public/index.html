Frequently Asked Questions

Is Zenwa secure?

Yes, Zenwa uses encrypted storage for all private keys. However, as a custodial wallet, we recommend using it for everyday transactions rather than storing large amounts.

How do I start using Zenwa?

Simply open Telegram, search for @zenwallethederabot, start a chat, and follow the instructions to create your wallet.

What tokens can I manage with Zenwa?

Zenwa supports HBAR and all custom tokens on the Hedera network. You can create, send, and receive any fungible token.

Are there any fees for using Zenwa?

Zenwa doesn't charge any fees for basic operations. You only pay the standard Hedera network fees, which are typically fractions of a cent.
