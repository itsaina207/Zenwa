Airdrop Creation
Underlying Transaction: TokenAirdropTransaction
Under the hood, the airdrop feature uses Hedera’s TokenAirdropTransaction, introduced in HIP-904, which allows distributing fungible tokens and NFTs to multiple recipients in one atomic transaction 
Hedera
Hedera
. This transaction automatically associates tokens for recipients with available auto-association slots, with the sender covering association and auto-renewal fees 
Hedera
. If a recipient lacks association capacity, the network records a pending airdrop instead of failing, enabling recipients to claim when ready 
Hedera
. The sender pays for transfer fees, association rent for new token accounts, and a small spam-deterrent fee per pending airdrop entry 
Hedera
.

Airdrop Claiming
Underlying Transaction: TokenClaimAirdropTransaction
Recipients can accept pending airdrops using TokenClaimAirdropTransaction, which finalizes both the auto-association (if needed) and the token transfer in one combined operation 
Hedera
. This transaction requires the recipient’s signature (and the fee-payer’s if different), with the recipient covering only the transaction fee 
Hedera
. Once claimed, the tokens are transferred irreversibly to the recipient’s account and removed from pending state

.
